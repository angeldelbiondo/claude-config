- Lo que solo decide la familia: precios, cuentas a nombre de la empresa (Cloudflare, Tilopay, GA4/Meta), dominios y DNS (las webs viejas las hizo Tecnesy), quién vende el varadero (Vista Mar Boat Yard vs Panama Shipyard Services), fotos reales.
