Dos correcciones de estilo de trabajo que Angel dio el 2026-08-25, en el proyecto [[project-trading-algoritmico]]:

**1. No usar mapas visuales ni widgets de visualización.** Consumen créditos y él no los quiere para eso. Explicar con texto, tablas y bullets.

**2. Bajar la densidad.** Dijo textual *"me está costando un poco entender el ritmo de lo que vas haciendo"*. Venía tirando varios hallazgos técnicos por respuesta, cada uno con matices y reversiones. Menos cosas por respuesta, explicaciones simples sin tecnicismos, y confirmar dónde estamos parados antes de avanzar.

**Why:** Angel no es quant y arrancó de cero en el tema. Si no puede seguir el hilo, no puede tomar decisiones sobre su propio proyecto — y termina delegando a ciegas, que es exactamente lo que este proyecto trata de evitar.

**How to apply:** una idea principal por respuesta. Tablas cortas antes que párrafos. Cuando un hallazgo sea técnico, primero qué significa en la práctica y después el detalle. Y **documentar todo en el vault de Obsidian** — él pidió explícitamente apoyarse en eso porque *"a quien le va a servir lo que está ahí es a vos"*, para cuando pierda contexto naturalmente.
