VendingHubPTY sigue siendo un proyecto personal de Angel (2026-10-11). Angel dijo que al levantarlo se constituirá en empresa más adelante; hoy no hay sociedad ni correo corporativo.

**Why:** Los términos de Claude Startups dicen que la solicitud la presenta "the Company on whose behalf an application is being submitted". Declarar una empresa inexistente sería falso. El formulario además exige correo corporativo, que hoy no existe.

**How to apply:** No enviar la solicitud de Claude Startups como empresa todavía. Orden cuando llegue el momento: constituir la sociedad, dominio y correo corporativo, publicar la web si el formulario la pide, y recién entonces aplicar. El borrador de respuestas está en `solicitud-claude-startups.md` (carpeta Claude Code Proyects).
